Lantern Thief is a top-down stealth game: sneak through a moonlit museum, steal three relics, and slip out the green exit without ever being seen. Guards patrol with vision cones, crates block their sight, and shadows hide you — throw pebbles to distract them, or hold Shift to sneak. Open game/index.html in a desktop browser to play.

## Controls

| Key | Action |
| --- | --- |
| W A S D / arrows | Move |
| Shift (hold) | Sneak — slower, quieter, harder to spot |
| Mouse click | Throw a pebble (3 per run) — guards investigate the noise |
| P | Pause |
| R | Restart |
| M | Mute |

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
